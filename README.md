# 🐋 dsh 皮肤

在今天，做一套皮肤无比的简单，只需要一次对话。

## 为什么 dsh 需要皮肤

dsh 的界面是给长时间工作设计的：token 驱动、语义化配色、深浅两套方案做得一丝不苟。这是它的优点，也是它的代价——"一丝不苟"盯上几百个小时，就变成了"一成不变"。开发者会花一个下午调自己的编辑器主题，会给终端配一套顺眼的配色，会在聊天软件里挑一个最舒服的气泡颜色，唯独工作台常常是出厂模样。不是因为不想换，是因为换不动：它太"正确"了，正确到你不知道该从哪下手。

皮肤解决的就是这件事。它不改功能、不添噪音、不动你熟悉的每一个按钮的位置，只改变你在屏幕前抬起头时的第一眼。而 dsh 恰好给这种改变留了一扇体面的门：整个界面只消费 `--dsw-alias-*` 语义 token。皮肤只需要重指这些变量、再在界面背后铺一层背景，整套界面就会跟着改头换面——这是这个产品留给我们这些"想让它好看一点"的人的、受宠若惊的入口。

## 我们能做到的，其实有限

我们找来了一整个动效组件库，一百二十多个组件，从流动的极光、液态金属，到超空间旅行、点击粒子风暴，挨个评估了一遍。

结论分四档：
一小撮是纯 CSS，可以直接吸收；一部分需要一层轻量脚本；剩下的一大半——那些真正让人"哇"出来的——全是 WebGL 着色器，需要三 d 引擎，装不进一张样式表。
我们还试过换光标、做磁吸、做全局粒子雨，最后都撤了。

撤的原因很简单：
这是一件面向 harness 开发者做的衣服，技术不再是吸引力，安静才是。
换光标会打断肌肉记忆，粒子雨会吃掉注意力，玻璃做得太透会吃掉文字。所以这个皮肤包最后选择了如下边界：

- 只用 CSS 和一层极轻的指针脚本，没有引擎、没有网络请求、没有图片资源；
- 不改布局、不改字体、不改任何交互——那些属于产品本身；
- 每款背景都是一段内嵌 SVG 场景，单文件即全部，离线可用，转发给朋友就是一次完整的搬家；
- 所有动效尊重系统的「减弱动态效果」：安静是默认值，热闹需要你自己打开。

复杂这件事，我们克制住了。留下的是能长期相处的东西：一张像样的背景、一层通透的玻璃、几个点到为止的小动效。
这就够了。

## 五件衣服

**🌐 DeepSeek 官网（deepseek-web）—— 贴合官网风格的衍生版**

这是整个皮肤包的起点，也是与官网风格最贴合的一件。品牌蓝 `#4d6bfe` 直接取自官网样式表，背景沿用了官网的极光、网格与胶片颗粒，鲸鱼徽标像官网那样轻轻摆动，输入框描边带着一圈旋转的星光。

它把官网的观感完整移植到了工作台上——产品不是网站，所以它是衍生，不是复刻；但也正因为是衍生，它处处收着分寸：纯 CSS，一行脚本都没有。如果你只想要"官网同款"，选它，故事到这里就可以结束。

**⛰️ 远山青黛（dusk-mountains）—— 夕阳的陪伴**

青黛是一种很老的颜料，古人画远山用的就是它。这件皮肤浅色是黎明的粉紫，深色是星空、月亮和层层叠叠的山脊——黄昏把山染成靛蓝的时候，往往也是你写代码写得最久的时候。它把夕阳留在界面背后，不声不响，像一句不需要说话的陪伴。

**🌃 霓虹都市（neon-night）—— 温柔的怀抱**

赛博落日在深色模式里缓缓升起，带着扫描线的缺口，脚下是一条发光的地板。粉色系的点缀在一众蓝色里相当出格，但它不刺眼：深夜里，它像一条温柔的、发光的街，把你整个人裹进去。写代码写到凌晨的人，需要的正是这样一个怀抱。

**🌊 深海（deep-sea）—— 傍晚的沉思**

浅色是光束穿透的碧蓝浅滩，深色是深渊里的光束和缓缓上升的气泡。没有山、没有落日，只有水、光和气泡。它是留给沉思的：傍晚关掉会议、摘下耳机，对着屏幕想清楚一件事的时候，这片海会陪你想。

**✨ 超级皮肤（super）—— 自我的突破**

官网蓝的深空星云做底，加上我们全部的本事：光标跟随描边、聚光灯、3D 倾斜、发送键扫光、点击粒子。它是五件衣服里唯一不守规矩的一件——不是穿给别人看的，是穿给自己看的：当你想试试，自己还能多喜欢一个界面的时候，穿它。

## 动效的分寸

我们给每一颗星星都算过账：

- 🧲 光标跟随描边——输入框的高光会看向你的光标，移开后恢复自动巡航；
- 🔦 聚光灯——光标进入输入框，光斑跟过去，离开就熄灭；
- 🎯 3D 倾斜——输入框随光标微微侧身，最多两度半，绝不夸张；
- ✨ 发送键扫光——悬停时一道白光斜扫过去；
- 🎆 点击粒子——每次点击迸出十颗品牌色的小星星，半秒后自行消失。

系统开启「减弱动态效果」时，整套动效自动静止，只剩配色和背景。
我们对"皮肤"的全部理解，就是：你可以有，但得能一键安静下来。

## 做包时踩过的坑

这段写下来，是为了让你知道它为什么长现在这样。

**第一版被吐槽"没看出来哪里变化"。** 那是真的——我们第一版只动了几个颜色 token，克制得过了头。于是才有了鲸鱼摆动、星光描边、背景场景这些"看得出"的东西。克制的底线是：你得先看得出来，才谈得上喜欢。

**浅色模式下背景几乎透不出来。** 玻璃做得太实，浅色场景被白雾盖住。后来把玻璃调薄、把场景加深，背景才真正"穿"在了身上。

## 快速开始

**在产品里穿**：打开 dsh Web → 设置 → 常规 → 皮肤 → 点一个选择块。选择会记住，下次打开还在。

**用浏览器扩展穿**：安装 Stylus（或任意 UserCSS 扩展）→ 新建样式 → 粘贴对应 `.user.css` 的全部内容 → 应用范围填你的部署地址 → 保存。任何部署实例都能用，不用改代码。

> 其它 profile 想内置皮肤库：在 cordis.patch.yml 里插入 `- id: ui-skin-gallery`（name 为 `@deepseek-ai/dsh-client-ui-skin-gallery`），并声明包依赖。

## 常见问题

**Q：选完没变化？** 先强刷（macOS `Cmd+Shift+R` / Windows·Linux `Ctrl+Shift+R`）；确认设置页里选择块是选中态；再检查浏览器有没有 Dark Reader 之类的扩展在打架。

**Q：这也太素了吧？** 对，这是故意的。想要更炫的，把 `super.user.css` 里的场景换成你自己的 SVG，或者去给那些 WebGL 效果写一个插件——我们的克制不构成你的上限。

**Q：换机器皮肤还在吗？** 产品内的选择保存在本机 `ui-skin.skin`；扩展方式跟随浏览器同步。把本包转发给朋友，即可原样复刻。
